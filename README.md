# 🎫 Customer Support Ticket Analyzer

A Python-based mini project to manage and analyze customer support tickets.  
This system helps in tracking issues, cleaning data, categorizing problems, and generating meaningful insights from customer complaints.

---

## 🚀 Features

- ✅ Add, update, delete tickets  
- ✅ Search tickets by keywords  
- ✅ Filter by priority (High/Medium/Low)  
- ✅ Filter by status (Open/Closed)  
- ✅ Close tickets  
- ✅ Export filtered data to CSV  
- ✅ Data cleaning using regex  
- ✅ Keyword-based issue categorization  
- ✅ Ticket analysis with insights  
- ✅ Priority summary & percentage report  

---

## 📊 Analysis Capabilities

- Identifies **Performance Issues** (slow, delay, lag)  
- Detects **Failure Issues** (error, crash, not working)  
- Tracks **Quality Issues** (poor, bad)  
- Highlights **Uncategorized tickets**  
- Generates **percentage-based insights**

---

## 🧠 Insights Generated

- Distribution of issues across categories  
- Percentage of tickets by type  
- Identification of major problem areas  
- Helps in improving customer service decisions  

---

## 🛠️ Technologies Used

- Python  
- CSV (for data storage)  
- Regex (for data cleaning)
